# 🍔 Guin's Burger - Cardápio Digital

Cardápio digital interativo do **Guin's Burger**, desenvolvido com HTML5, CSS3 e JavaScript puro, integrado diretamente com o WhatsApp para agilizar os pedidos.

## 🚀 Funcionalidades
* **Navegação por Categorias:** Abas rápidas para Entradas, Mais Pedidos, Tradicionais, Gourmets, Acréscimos, Bebidas, Sucos e Sodas.
* **Carrinho Inteligente:** Adicione itens, altere quantidades, remova produtos e acompanhe o valor total em tempo real.
* **Checkout via WhatsApp:** Envio do pedido formatado de forma limpa e organizada diretamente para o número do estabelecimento.
* **Informações Úteis:** Endereço com link direto para o Google Maps e horário de funcionamento.

## 🛠️ Tecnologias Utilizadas
* HTML5
* CSS3 (Estilização personalizada com tema escuro e dourado)
* JavaScript (Manipulação do DOM e lógica do carrinho)

## 📍 Onde encontrar
* **Localização:** Linhares, ES
* **Funcionamento:** Terça a Domingo, das 18h às 23h
